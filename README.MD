# Emergency Hotline

An emergency contact directory — browse and quickly find hotline numbers for different emergency situations. Built as a hands-on JavaScript DOM practice project.

## Live

https://creativeghalib.github.io/B12-A5-Emergency-Hotline/

## Built with

- HTML
- Tailwind CSS + DaisyUI
- Vanilla JavaScript

## Features

- Browse emergency contacts by category
- Responsive layout for mobile and desktop
